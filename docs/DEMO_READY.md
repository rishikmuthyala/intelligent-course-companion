## ⚡ Quick Troubleshooting

### Issue: Frontend not loading
**Solution:** Check if the dev server is running:
```bash

```

### Issue: Courses not showing
**Solution:** The backend isn't running. Either:
1. Start the backend (see above)
2. Use the 3 demo courses that appear automatically

**Solution:** Backend is required for chat. Start it:
