# 🎓 AI Course Companion - LinkedIn Demo Guide

## 🚀 What is it?
An intelligent learning assistant that syncs with your Canvas courses and provides AI-powered Q&A using RAG (Retrieval-Augmented Generation). Built with React, TypeScript, Python, and ChromaDB.

## ✨ Key Features

### 1. **Beautiful Landing Page**
- Modern, responsive design with smooth animations
- Clear value proposition
- Gradient backgrounds and glassmorphism effects

### 2. **Smart Dashboard**
- View all your synced courses
- AI-generated course summaries
- Quick stats and progress tracking
- Interactive course cards with hover effects

### 3. **Intelligent Chat Interface**
- Real-time Q&A with course content
- Powered by RAG pipeline
- Context-aware responses
- Beautiful message bubbles with smooth animations

## 🎨 Design Highlights

### Modern UI/UX
- **Gradient Accents**: Indigo to purple gradients throughout
- **Smooth Animations**: Slide-up, fade-in, and scale effects
- **Glassmorphism**: Backdrop blur effects for a premium feel
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Custom Scrollbars**: Thin, elegant scrollbars that match the theme

### Visual Elements
- Lucide React icons for crisp, modern iconography
- Tailwind CSS for rapid, consistent styling
- Custom animations with CSS keyframes
- Hover states and transitions on all interactive elements

## 🛠️ Tech Stack

### Frontend
- **React 19** with TypeScript
- **Vite** for lightning-fast development
- **Tailwind CSS** for styling
- **Lucide React** for icons
- **Axios** for API calls

### Backend
- **Python FastAPI** for REST API
- **ChromaDB** for vector storage
- **OpenAI Embeddings** for semantic search
- **RAG Pipeline** for intelligent Q&A

## 🚀 Quick Demo Steps

1. **Start the Backend**:
   ```bash
   cd intelligent-course-companion/backend
   python main.py
   ```

2. **Start the Frontend** (already running!):
   ```bash
   cd intelligent-course-companion/frontend
   npm run dev
   ```

3. **Open Browser**: 
   - Navigate to `http://localhost:5173`
